# REQ_004 設計文件：應用程式國際化實現

## 1. 設計概述

### 1.1 目標

實現完整的國際化（i18n）系統，支援繁體中文、簡體中文和英文三種語言，並與現有配置系統整合。

### 1.2 技術選型

- **i18next**：業界標準的國際化框架
- **react-i18next**：i18next 的 React 綁定
- **JSON**：翻譯文件格式
- **配置整合**：與 REQ_003 的配置系統整合

### 1.3 設計原則

- 最小侵入性：盡量不破壞現有代碼結構
- 高擴展性：易於添加新語言
- 性能優化：懶加載翻譯文件
- 用戶友好：即時切換，無需重啟

### 2.2 資料流程

```
用戶選擇語言
    ↓
GeneralSettingsPage.handleLanguageChange()
    ↓
i18n.changeLanguage(newLang)
    ↓
所有組件重新渲染（使用新語言）
    ↓
SaveConfig() → 儲存到 config.json
    ↓
下次啟動時從 config.json 讀取
```

### 4.3 i18n 初始化配置

**frontend/src/i18n.js**

```javascript
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';

// 導入翻譯資源
import zhTW from './locales/zh-TW/translation.json';
import zhCN from './locales/zh-CN/translation.json';
import en from './locales/en/translation.json';

// 初始化 i18next
i18n
  .use(initReactI18next) // 綁定 react-i18next
  .init({
    // 語言資源
    resources: {
      'zh-TW': {
        translation: zhTW
      },
      'zh-CN': {
        translation: zhCN
      },
      'en': {
        translation: en
      }
    },
    
    // 預設語言（會被配置文件覆蓋）
    lng: 'zh-TW',
    
    // 找不到翻譯時的回退語言
    fallbackLng: 'zh-TW',
    
    // 調試模式（生產環境應設為 false）
    debug: false,
    
    // 插值設定
    interpolation: {
      escapeValue: false // React 已經處理 XSS
    },
    
    // 命名空間（目前只用預設的 translation）
    ns: ['translation'],
    defaultNS: 'translation'
  });

export default i18n;
```

```javascript
import { useState, useEffect } from 'react';
import { useTranslation } from 'react-i18next'; // 新增
import { Card, CardHeader, CardTitle, CardDescription, CardContent } from '@/components/ui/card';
import { Input } from '@/components/ui/input';
import { Button } from '@/components/ui/button';
import { Select, SelectContent, SelectItem, SelectTrigger, SelectValue } from '@/components/ui/select';
import { Label } from '@/components/ui/label';
import { GetConfig, SaveConfig, TestDatabaseConnection } from '../../wailsjs/go/main/App';

function GeneralSettingsPage() {
  const { t, i18n } = useTranslation(); // 新增：使用翻譯 hook
  const [currentLanguage, setCurrentLanguage] = useState('zh-TW'); // 新增

  // 載入配置並設定語言
  useEffect(() => {
    loadConfig();
  }, []);

  const loadConfig = async () => {
    try {
      const config = await GetConfig();
      if (config && config.application && config.application.language) {
        const lang = config.application.language;
        setCurrentLanguage(lang);
        i18n.changeLanguage(lang); // 設定 i18n 語言
      }
    } catch (error) {
      console.error('Failed to load config:', error);
    }
  };

  // 處理語言切換
  const handleLanguageChange = async (newLang) => {
    try {
      // 立即更新 UI
      setCurrentLanguage(newLang);
      i18n.changeLanguage(newLang);
      
      // 儲存到配置文件
      const config = await GetConfig();
      if (!config.application) {
        config.application = {};
      }
      config.application.language = newLang;
      await SaveConfig(config);
    } catch (error) {
      console.error('Failed to save language setting:', error);
    }
  };

  return (
    <div className="max-w-4xl mx-auto">
      <div className="mb-8">
        <h1 className="text-4xl font-bold text-foreground mb-2">
          {t('settings.general.title')}
        </h1>
        <p className="text-lg text-muted-foreground">
          {t('settings.general.description')}
        </p>
      </div>

        <CardHeader>
          <CardTitle>{t('settings.general.appearance')}</CardTitle>
        </CardHeader>

          <div className="flex items-center justify-between py-3 border-b">
            <label className="text-sm font-medium">
              {t('settings.general.theme.label')}
            </label>

              <SelectTrigger className="w-40">
                <SelectValue placeholder={t('settings.general.theme.placeholder')} />
              </SelectTrigger>
              <SelectContent>
                <SelectItem value="light">

                </SelectItem>
                <SelectItem value="dark">
                  {t('settings.general.theme.dark')}
                </SelectItem>
                <SelectItem value="system">
                  {t('settings.general.theme.system')}
                </SelectItem>
              </SelectContent>
            </Select>
          </div>
          <div className="flex items-center justify-between py-3">
```

```javascript
function AdvancedSettingsPage() {
  const { t } = useTranslation(); // 新增
  
  // 資料庫設定
  const [dbType, setDbType] = useState('mssql');
  const [dbHost, setDbHost] = useState('localhost');
  const [dbPort, setDbPort] = useState('1433');
  const [dbUsername, setDbUsername] = useState('');
  const [dbPassword, setDbPassword] = useState('');
  const [dbDatabase, setDbDatabase] = useState('');
  const [showPassword, setShowPassword] = useState(false);
  
  // 測試結果
  const [testResult, setTestResult] = useState(null);
  const [isTesting, setIsTesting] = useState(false);
  const [isSaving, setIsSaving] = useState(false);

  // 載入設定
  useEffect(() => {
    loadConfig();
  }, []);

  const loadConfig = async () => {
    try {
      const config = await GetConfig();
      if (config && config.database) {
        setDbType(config.database.type || 'mssql');
        setDbHost(config.database.host || 'localhost');
        setDbPort(String(config.database.port || 1433));
        setDbUsername(config.database.username || '');
        setDbPassword(config.database.password || '');
        setDbDatabase(config.database.database || '');
      }
    } catch (error) {
      console.error('Failed to load config:', error);
    }
  };

  const handleTestConnection = async () => {
    setIsTesting(true);
    setTestResult(null);
    
    try {
      const db = {
        type: dbType,
        host: dbHost,
        port: parseInt(dbPort),
        username: dbUsername,
        password: dbPassword,
        database: dbDatabase
      };
      
      const result = await TestDatabaseConnection(db);
      
      // 根據結果設定訊息
      const message = result.success 
        ? t('settings.advanced.database.messages.connectionSuccess')
        : t('settings.advanced.database.messages.connectionFailed');
      
      setTestResult({
        ...result,
        message: message
      });
    } catch (error) {
      setTestResult({
        success: false,
        message: t('settings.advanced.database.messages.connectionFailed'),
        latency: 0
      });
    } finally {
      setIsTesting(false);
    }
  };

  const handleSaveConfig = async () => {
    setIsSaving(true);
    
    try {
      const config = await GetConfig();
      config.database = {
        type: dbType,
        host: dbHost,
        port: parseInt(dbPort),
        username: dbUsername,
        password: dbPassword,
        database: dbDatabase
      };
      
      await SaveConfig(config);
      setTestResult({
        success: true,
        message: t('settings.advanced.database.messages.configSaved'),
        latency: 0
      });
    } catch (error) {
      setTestResult({
        success: false,
        message: t('settings.advanced.database.messages.saveFailed'),
        latency: 0
      });
    } finally {
      setIsSaving(false);
    }
  };

  return (
    <div className="max-w-4xl mx-auto">
      <div className="mb-8">
        <h1 className="text-4xl font-bold text-foreground mb-2">
          {t('settings.advanced.title')}
        </h1>
        <p className="text-lg text-muted-foreground">
          {t('settings.advanced.description')}
        </p>
      </div>
      
      <Card>
        <CardHeader>
          <CardTitle>{t('settings.advanced.database.title')}</CardTitle>
          <CardDescription>
            {t('settings.advanced.database.description')}
          </CardDescription>
        </CardHeader>
        <CardContent className="space-y-4">
          <div className="grid gap-4">
            <div className="space-y-2">
              <Label htmlFor="db-type">
                {t('settings.advanced.database.type.label')}
              </Label>
              <Select value={dbType} onValueChange={setDbType}>
                <SelectTrigger id="db-type">
                  <SelectValue />
                </SelectTrigger>
                <SelectContent>
                  <SelectItem value="mssql">

                  </SelectItem>

                    {t('settings.advanced.database.type.mysql')}

              </Select>
            </div>

              <div className="space-y-2">

                  {t('settings.advanced.database.host.label')}
                </Label>

                  id="db-host"
                  placeholder={t('settings.advanced.database.host.placeholder')}
                  value={dbHost}
                  onChange={(e) => setDbHost(e.target.value)}
                />
              </div>
              <div className="space-y-2">
                <Label htmlFor="db-port">
                  {t('settings.advanced.database.port.label')}
                </Label>
                <Input
                  id="db-port"

                  value={dbPort}
                  onChange={(e) => setDbPort(e.target.value)}
                />
              </div>
            </div>

            <div className="space-y-2">
              <Label htmlFor="db-username">
                {t('settings.advanced.database.username.label')}
              </Label>
              <Input
                id="db-username"
                placeholder={t('settings.advanced.database.username.placeholder')}
                value={dbUsername}
                onChange={(e) => setDbUsername(e.target.value)}
              />
            </div>

            <div className="space-y-2">
              <Label htmlFor="db-password">
                {t('settings.advanced.database.password.label')}
              </Label>
              <div className="flex gap-2">
                <Input
                  id="db-password"
                  type={showPassword ? "text" : "password"}
                  placeholder={t('settings.advanced.database.password.placeholder')}
                  value={dbPassword}
                  onChange={(e) => setDbPassword(e.target.value)}
                  className="flex-1"
                />
                <Button
                  type="button"
                  variant="outline"
                  onClick={() => setShowPassword(!showPassword)}
                  className="px-3"
                >
                  {showPassword 
                    ? t('settings.advanced.database.password.hide')
                    : t('settings.advanced.database.password.show')
                  }
                </Button>
              </div>
            </div>

            <div className="space-y-2">
              <Label htmlFor="db-database">
                {t('settings.advanced.database.database.label')}
              </Label>
              <Input
                id="db-database"
                placeholder={t('settings.advanced.database.database.placeholder')}
                value={dbDatabase}
                onChange={(e) => setDbDatabase(e.target.value)}
              />
            </div>
          </div>

          <div className="flex gap-3 pt-4">
            <Button 
              onClick={handleTestConnection}
              disabled={isTesting || !dbHost || !dbUsername || !dbDatabase}
              variant="outline"
            >
              {isTesting 
                ? t('settings.advanced.database.actions.testing')
                : t('settings.advanced.database.actions.testConnection')
              }
            </Button>
            <Button 
              onClick={handleSaveConfig}
              disabled={isSaving || !dbHost || !dbUsername || !dbDatabase}
            >
              {isSaving 
                ? t('settings.advanced.database.actions.saving')
                : t('settings.advanced.database.actions.saveConfig')
              }
            </Button>
          </div>

          {/* 預留測試結果區域空間，避免畫面跳動 */}
          <div className="mt-4 min-h-[80px]">
            {testResult && (
              <div className={`p-4 rounded-lg border transition-all duration-200 ${
                testResult.success 
                  ? 'bg-green-50 border-green-200 text-green-800' 
                  : 'bg-red-50 border-red-200 text-red-800'
              }`}>
                <div className="flex items-start gap-2">
                  <span className="text-lg">
                    {testResult.success ? '✓' : '✗'}
                  </span>
                  <div className="flex-1">
                    <p className="font-medium">{testResult.message}</p>
                    {testResult.success && testResult.latency > 0 && (
                      <p className="text-sm mt-1">
                        {t('settings.advanced.database.messages.latency', { value: testResult.latency })}
                      </p>
                    )}
                  </div>
                </div>
              </div>
            )}
          </div>
        </CardContent>
      </Card>
    </div>
  );
}

export { GeneralSettingsPage, AdvancedSettingsPage };
```

在 App.jsx 的最上層組件中，添加初始化邏輯：

```javascript
import { useEffect } from 'react';
import { useTranslation } from 'react-i18next';
import { GetConfig } from './wailsjs/go/main/App';

function App() {
  const { i18n } = useTranslation();
  const [currentPage, setCurrentPage] = useState('settings-general');

  useEffect(() => {

        if (config && config.application && config.application.language) {
          i18n.changeLanguage(config.application.language);
        }
      } catch (error) {

      }
    };
    
    initLanguage();
  }, []);

  // ... 其他代碼
}
```

### 5.2 語言切換流程

```
1. 用戶在 GeneralSettingsPage 選擇新語言
   ↓
2. handleLanguageChange() 被調用
   ↓
3. 更新 React state (currentLanguage)
   ↓
4. 調用 i18n.changeLanguage(newLang)
   ↓
5. 所有使用 useTranslation() 的組件自動重新渲染
   ↓
6. 調用 GetConfig() 獲取當前配置
   ↓
7. 更新 config.application.language
   ↓
8. 調用 SaveConfig() 儲存到 JSON 文件
   ↓

```

## 9. 潛在問題與解決方案

### 問題 1：配置文件不存在

**解決方案**：在 GetConfig() 中處理，返回預設配置

```go
func (s *ConfigService) GetConfig() *Config {
    if s.config == nil {
        return s.createDefaultConfig()
    }
    return s.config
}
```

### 問題 2：語言切換後部分組件未更新

**解決方案**：確保所有組件都使用 `useTranslation()` hook，而不是在組件外部調用 `t()`

```javascript
// ❌ 錯誤：不會響應語言變化
const LABEL = t('some.key');

function MyComponent() {
  return <div>{LABEL}</div>;
}

// ✅ 正確：會響應語言變化
function MyComponent() {
  const { t } = useTranslation();
  return <div>{t('some.key')}</div>;
}
```

### 問題 3：翻譯鍵拼寫錯誤

**解決方案**：
1. 使用 TypeScript + i18next 類型定義（未來優化）
2. 在開發時啟用 i18n debug 模式
3. 建立翻譯鍵文檔

### 問題 4：翻譯不一致

**解決方案**：
1. 建立術語表（Glossary）
2. 統一翻譯審查
3. 使用翻譯管理工具
