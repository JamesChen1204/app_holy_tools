# REQ_002: 集成 Shadcn UI 設計系統

## 📋 需求概述

將 Shadcn UI 組件庫集成到 PowerMoat Management Tools 中，統一應用的設計語言和組件規範，提升 UI 的一致性和開發效率。

## 🎯 需求目標

1. 建立基於 Tailwind CSS 的設計系統
2. 集成 Shadcn UI 組件庫
3. 統一應用的視覺風格和交互規範
4. 提供可復用的 UI 組件

## 🛠 技術方案

### 2. Shadcn UI 配置

#### 安裝依賴

```bash
npm install class-variance-authority clsx tailwind-merge
npm install lucide-react
npm install -D tailwindcss-animate
```

#### components.json

```json
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "default",
  "rsc": false,
  "tsx": false,
  "tailwind": {
    "config": "tailwind.config.js",
    "css": "src/index.css",
    "baseColor": "slate",
    "cssVariables": true
  },
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils"
  }
}
```

#### src/lib/utils.js

```javascript
import { clsx } from "clsx"
import { twMerge } from "tailwind-merge"

export function cn(...inputs) {
  return twMerge(clsx(inputs))
}
```

## 🎨 設計規範

### 色彩系統

- **Primary**: 主要品牌色 - 藍色系 (#667eea)
- **Secondary**: 次要色 - 淺灰色
- **Accent**: 強調色 - 紫色系 (#764ba2)
- **Destructive**: 危險/錯誤色 - 紅色系
- **Muted**: 弱化色 - 淺灰色

### 間距系統

使用 Tailwind 的間距單位：
- 基礎單位: 0.25rem (4px)
- 常用間距: 2 (8px), 4 (16px), 6 (24px), 8 (32px)

### 字體系統

```css
font-family: "Nunito", -apple-system, BlinkMacSystemFont, "Segoe UI", 
             "Roboto", "Oxygen", "Ubuntu", "Cantarell", "Fira Sans", 
             "Droid Sans", "Helvetica Neue", sans-serif;
```

### 圓角系統

- 小: 0.375rem (6px)
- 中: 0.5rem (8px)
- 大: 0.75rem (12px)

### 陰影系統

- 小: `0 1px 2px 0 rgb(0 0 0 / 0.05)`
- 中: `0 4px 6px -1px rgb(0 0 0 / 0.1)`
- 大: `0 10px 15px -3px rgb(0 0 0 / 0.1)`

## 📊 組件使用示例

### Button 組件

```jsx
import { Button } from "@/components/ui/button"

export default function Example() {
  return (
    <div className="flex gap-4">
      <Button>Default</Button>
      <Button variant="secondary">Secondary</Button>
      <Button variant="destructive">Destructive</Button>
      <Button variant="outline">Outline</Button>
      <Button variant="ghost">Ghost</Button>
    </div>
  )
}
```

### Card 組件

```jsx
import {
  Card,
  CardContent,
  CardDescription,
  CardFooter,

export default function Example() {
```

```jsx

```

## 🎯 預期成果

1. **統一的設計語言**: 所有組件遵循相同的設計規範
2. **提升開發效率**: 使用現成的高質量組件
3. **更好的用戶體驗**: 一致的交互和視覺效果
4. **易於維護**: 組件化和模塊化的代碼結構
5. **主題支持**: 支持淺色/深色模式切換
6. **響應式設計**: 在不同屏幕尺寸下都有良好的表現

## 📝 注意事項

1. **漸進式遷移**: 不需要一次性替換所有組件，可以逐步遷移
2. **保持兼容性**: 確保新組件與現有功能兼容
3. **性能考慮**: Tailwind 的 JIT 模式可以減少最終打包體積
4. **文檔更新**: 更新組件使用文檔和開發指南
5. **團隊培訓**: 確保團隊成員熟悉新的組件系統
